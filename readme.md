# Monday Morning Challenge 

Web Developer & Designer UI/UX design 

[View Monday Morning Challenge](https://olbotron.github.io/monday-morning-challenge/profile.html)


This project creates a centered profile card using Bootstrap. The card includes a circular profile image, 
a name, a short bio, and a "Follow" button. It is responsive and utilizes Bootstrap's card components and utility classes to ensure visual appeal.

## Usage

The project creates a centered profile card that includes:
- A circular profile image.
- A name.
- A short bio ("Web Developer & Designer").
- A "Follow" button styled using Bootstrap.
